How to use

Open this file in any browser (including iPhone Safari). Bookmark it. The dashboard updates itself every 30 seconds with live prices from CoinGecko. Green badges mean the coin is within the $0.99–$1.01 peg band. Red means it has depegged below $0.99. Amber means it has depegged above $1.01. Volume spike banners appear if trading volume suddenly jumps more than 3× its recent average. If you see a temporary data error, wait a moment or click Refresh now — free data sources sometimes pause briefly. No login, no install, no code required.

Data source: CoinGecko free API. For alerts, Telegram, or WebSocket streaming, use the Python detector in this repository. Minutes matter when a peg breaks.
