How to use

This is a zero-code tool. No install, no login, no terminal. Just open and monitor.

  1. Open this file in any browser (Chrome, Safari, Firefox — works perfectly on iPhone).
  2. Bookmark it or add to home screen for one-tap access.
  3. Prices refresh automatically every 30 seconds from CoinGecko (with Coinbase cross-check).
  4. Green badge = within $0.99–$1.01. Red = depeg down. Amber = depeg up. Gray = no data.
  5. Volume spike and cross-source divergence alerts appear as banners at the top when triggered.
