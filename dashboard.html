How to use

  1. Bookmark this page. Open it any time in any browser (including iPhone Safari).
  2. The six cards show live prices, 24h change, market cap, and status for USDT, USDC, DAI, FDUSD, PYUSD, and TUSD.
  3. Green badge = OK (inside $0.99–$1.01). Red = depeg down. Amber = depeg up. Gray = no data. Cards pulse on depeg.
  4. Volume spike banners appear if 24h volume jumps more than 3× recent median (tracked locally).
  5. Data refreshes every 30 seconds. No install, no login, no code required. Last-good data shown on rate limits.
