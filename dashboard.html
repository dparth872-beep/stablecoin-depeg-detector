How to use

  1. Bookmark this page. It works in any modern browser (including iPhone Safari) and refreshes automatically every 30 seconds.
  2. Green badge = peg is healthy ($0.99–$1.01). Red = depeg down. Amber = depeg up. Gray = no data from the API. Deviation in basis points shown under price.
  3. A banner appears at the top if volume spikes above 3× the recent median or a depeg is detected. The peg bar shows price position relative to the $0.99–$1.01 safe zone.
  4. No login, no install, no code to run. Just open the file. Data comes from CoinGecko’s free public API.
