How to use

  1. Bookmark this page. It works in any browser, including iPhone Safari — no install, no login, no account.
  2. Prices refresh automatically every 30 seconds from CoinGecko. Use the Refresh now button for an immediate pull.
  3. Green badge = price inside the $0.99–$1.01 safe band. Red = depeg down. Amber = depeg up.
  4. The peg bar shows position relative to $1.00; the green zone is the safe band. Marker is the current price.
  5. Banners at the top flag volume spikes or depegs when detected. Leave it open on a second monitor or phone. Minutes matter when a peg breaks.
  6. If you see a rate-limit message, wait a minute or click Refresh now — CoinGecko’s free API is generous but not unlimited.
