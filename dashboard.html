How to use

Open this file in any modern browser (Chrome, Safari, Firefox, Edge). No install, no login, no code.

  • Each card shows live price, 24h change, and status for one stablecoin.
  • Green OK means price is between $0.99 and $1.01. Red is depeg down, amber is depeg up.
  • Volume spikes and cross-source divergences appear as banners at the top when detected.
  • Data refreshes automatically every 30 seconds from CoinGecko (with Coinbase fallback where available).
  • Works on iPhone Safari — just bookmark it or add to home screen.
