Stablecoin Depeg Intelligence

Real-time peg monitoring for funds, prop desks, and fintech teams

How to use

Open this file in any browser (including iPhone Safari). It refreshes every 30 seconds from CoinGecko. Green badges mean the coin is within $0.99–$1.01. Red or amber means a depeg. Volume spikes and cross-source issues appear as banners at the top. Bookmark it. No install, no login, no code required.
