How to use

  1. Open this file in any modern browser (Chrome, Safari, Firefox, Edge, including iPhone Safari).
  2. Bookmark the page. It auto-refreshes every 30 seconds with no login or install required.
  3. Green badge = OK (price between $0.99 and $1.01). Red = depeg down. Amber = depeg up. Gray = no data.
  4. BPS shows distance from the $1.00 peg. Volume spike banners appear when 24h volume exceeds 3× the session median baseline.
  5. Divergence banner flags >50 bps gaps between CoinGecko and Coinbase on supported pairs.
  6. Use the Refresh button for an immediate update. Alerts persist across page reloads via local storage. Just open and watch. Zero code, zero friction.

Data sources: CoinGecko free API (primary) + Coinbase spot for cross-check. Thresholds: $0.99–$1.01.
