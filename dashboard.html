How to use

Open this file in any browser (including iPhone Safari). It refreshes every 30 seconds from CoinGecko, with automatic Coinbase spot fallback if the free API is rate-limited. Green badges mean the coin is within $0.99–$1.01. Red means a depeg down; amber means a depeg up. The bar under each price shows peg deviation (safe zone $0.99–$1.01 highlighted). Volume spikes (current volume more than 3× the recent average) appear as a highlighted banner at the top. Bookmark it. No install, no login, no code required. Just open and watch.
