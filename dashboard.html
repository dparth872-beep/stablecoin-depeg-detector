How to use

This is a zero-code tool. No install, no login, no terminal required. Just open and monitor.

  1. Open this file in any modern browser (works perfectly on iPhone Safari).
  2. Bookmark it or add it to your home screen for one-tap access.
  3. Prices update automatically every 30 seconds from the CoinGecko free API, with Coinbase cross-checks for divergence.
  4. Green badge = OK (price between $0.99 and $1.01). Red = depeg down. Amber = depeg up. Gray = no data.
  5. Volume spikes and cross-source divergences appear as highlighted banners at the top when triggered.
  6. Each card shows the exact basis points from the $1.00 peg, a visual deviation bar (center mark = $1.00), and market cap.
  7. If the free API rate-limits, the dashboard keeps showing the last good data and notes the issue.
  8. Tap "Refresh Now" anytime for an immediate update.
