How to use

Open this file in any browser (including iPhone Safari). Bookmark it. The dashboard updates itself every 30 seconds with live prices from CoinGecko, cross-checked against Coinbase where available. Green badges mean the coin is within the $0.99–$1.01 peg band. Red means it has depegged below $0.99. Amber means it has depegged above $1.01. Volume spike banners appear if trading volume suddenly jumps more than 3× its recent average. Divergence banners flag when CoinGecko and Coinbase prices differ by more than 50 basis points. If you see a temporary data error, wait a moment or click Refresh now — free data sources sometimes pause briefly. No login, no install, no code required.
