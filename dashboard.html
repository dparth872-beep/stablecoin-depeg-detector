How to use

Open this file in any modern browser (including iPhone Safari). It auto-refreshes every 30 seconds from CoinGecko. Green badges mean the peg is healthy. Red means a depeg down (price below $0.99). Amber means a depeg up (above $1.01). Volume spike and cross-source divergence banners flag when prices differ by more than 50 basis points across sources. If you see a temporary data error, wait a moment or click Refresh now (or press R). No login, no install, no code required.

Data sources: CoinGecko free API (primary) + DefiLlama (fallback) + Coinbase public spot (secondary). For Telegram/email alerts or WebSocket streaming, use the Python detector in this repository.
