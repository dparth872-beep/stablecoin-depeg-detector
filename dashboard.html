How to use

  1. Bookmark this page. It updates automatically every 30 seconds using free public APIs.
  2. Green badge = price inside the $0.99–$1.01 safe band. Red = depeg down. Amber = depeg up. Gray = no data.
  3. Volume spike or cross-source divergence banners appear at the top when detected (volume history stored locally in your browser).
  4. Mini sparklines show recent price samples. Press R or the button to force refresh.
  5. Works on iPhone Safari and any modern browser. No login, no install, no code to run.
  6. For push alerts (Telegram/email), use the companion Python detector — see the README on GitHub.
